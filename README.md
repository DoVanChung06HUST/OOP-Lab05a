# Lab 05a - Quản lý thiết bị phòng thực hành

**Sinh viên:** Đỗ Văn Chung  
**MSSV:** 202418855

## Nội dung
Chương trình C# quản lý máy tính, máy in và máy chiếu trong phòng thực hành; áp dụng kế thừa, lớp trừu tượng, interface, kết tập và đa hình.

Chức năng: thêm thiết bị, kiểm tra trùng mã, in danh sách, tính chi phí bảo trì, liệt kê thiết bị cần bảo trì và kết nối/ngắt mạng.

## Cách chạy
Yêu cầu .NET 10 SDK. Mở Terminal tại thư mục chứa `Lab05a.csproj`:

```bash
dotnet run
```

Chạy kiểm thử bổ sung:

```bash
dotnet run -- --test
```
